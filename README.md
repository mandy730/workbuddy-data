# 🌸 妈妈的小宇宙 · 综合管理工作台

一个面向二胎妈妈的「育儿 + 外贸 + 自媒体 + 生活 + 财务」一体化管理台。粉紫少女风、圆角卡片、柔和渐变，手机和电脑数据可实时同步，可「添加到主屏幕」当 App 用。

## ✨ 功能一览

| 模块 | 内容 |
|------|------|
| 🏠 首页仪表盘 | 汇总各模块未完成事项，按「育儿周期性 / 商业项目推进 / 生活记录」三类分区展示进度 |
| 🌸 安安教育（7岁·二年级） | 语文 / 数学 / 英语 / 数独 / 中国舞 / 乒乓球 子任务，周度打卡 + 赛事考级提醒 |
| 🍼 宁宁教育（4岁） | 英语启蒙 / 亲子早教 每日亲子打卡 |
| 💼 外贸工作 | DARKO工作 / 日常待办 / AI工具学习，支持优先级标记 + 客户跟进节点（询盘→报价→打样→订单→出货） |
| 📕 小红书 | 爆款笔记收集 / 选题策划（含状态流）/ 发布后数据统计（阅读点赞收藏评论涨粉线索） |
| 💃 个人计划 | 爵士舞 / 阅读 / 生活购物清单，支持提醒 |
| 💰 财务管理 | 家庭日常 / 外贸收支 / 理财台账，收支记账 + 持仓收益 |

**通用能力**：每个分类支持无限层级子待办、重复周期（每天/每周/每月/自定义）、完成勾选（按周期独立记录）、备注与标签。

## 🚀 三种使用方式

### 方式一：本地直接打开（最快，无需联网）
直接双击 `index.html` 在浏览器打开即可使用，数据存在本机浏览器。

### 方式二：手机电脑实时同步（推荐，零成本）
部署自带的同步服务端，一个网址同时托管网页 + 实时同步：

1. 把 `mama-hub` 整个文件夹推到 GitHub
2. 打开 [render.com](https://render.com) → New → **Blueprint** → 选择仓库（会自动读取 `render.yaml`，免费额度即可）
3. 部署完成后得到公开网址，**手机和电脑都打开这个网址**
4. 点击右上角 ⚙ → 设置 → **「📡 使用当前网址作为同步地址」** → 勾选「开启自动同步」→ 保存
5. 完成！任意一端改动，另一端**实时**收到（基于 SSE 推送 + 30 秒保底轮询）

> 可选：在 Render 环境变量里设置 `SYNC_KEY`，所有同步需带该密钥，更安全。

### 方式三：用 JSONBin 等第三方存储
⚙ 设置里填写 JSONBin 的 Bin 地址（含 `/latest`）和密钥，开启自动同步即可。

### 不部署也能跨设备？
可以——用 ⚙ 里的「💾 导出备份 / 📂 导入备份」把数据文件在手机和电脑间手动搬。

## 🛠 本地跑同步服务端（开发者）
```bash
cd mama-hub
node sync-server.js        # 默认 http://localhost:3001
# 带密钥： SYNC_KEY=你的密钥 node sync-server.js
```
打开 http://localhost:3001 即是带同步的完整工作台。

## 📁 文件说明
- `index.html` / `styles.css` / `app.js`：前端应用（纯静态，无需构建）
- `sync-server.js`：零依赖同步服务端（静态托管 + 同步 API + SSE 实时推送）
- `manifest.json` / `sw.js` / `icon.svg`：PWA 安装与离线缓存
- `package.json` / `render.yaml`：一键部署配置
- `hub-data.json`：同步服务端落盘的数据（自动生成）
